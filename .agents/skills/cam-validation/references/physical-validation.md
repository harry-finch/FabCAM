# Physical validation boundary

The coding agent can prepare a protocol but cannot claim to have performed machine validation.

For ShopBot validation:

1. inspect generated machine code,
2. load in controller preview/simulation,
3. verify bounds and Z direction,
4. supervised air cut,
5. sacrificial material,
6. measure result,
7. compare against expected geometry.

Record machine/software version, tool, stock, zero convention, feed/plunge, observed behavior, measured dimensions, and anomalies.

A single successful part establishes a milestone, not general production readiness.
